# Truelancer 编程项目：一次性本地原型

本次要回答的问题：**Truelancer 的公开项目能否支撑一个能搜索、筛选、阅读中文摘要的个人选单页面？**

已完成。读取 100 个不同项目详情，保留 **88 条**；页面复用 `temp/100-programming-demo/` 的左右分栏布局，全部实验文件留在此目录。依用户要求采用一个既有页面布局，不另外制作设计变体。

## 打开

- 双击本目录 `index.html` 可离线查看；数据由同目录 `data.js` 加载，不需要 API 或数据库。
- 或在项目根目录运行：

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory temp/truelancer-programming-prototype
```

浏览器访问 <http://127.0.0.1:8769>。也可双击 `start.command`。服务器仅监听本机；它只提供静态文件，不运行来源采集。关闭终端可停止该服务器。

## 如何得到这些数据

1. 普通 Chrome 打开公开的 `https://www.truelancer.com/programming-freelancer-job`。
2. 使用页面可见的 Next 按钮逐页读取，不调用平台内部接口。
3. 按来源 ID 和原始网址去重，阅读卡片，排除培训、营销、全职招聘、纯硬件设计、需求不明、私密标记及明显重复内容。
4. 选取前 100 个候选，逐一导航至页面实际暴露的详情链接，只读取可见正文及页面时间节点属性。
5. 从详情提取预算与状态；时薪价格与“预计工时”分别保存，避免把工时误当预算。
6. 对时间节点 `datetime` 的 epoch 毫秒数与带时区的 `title` 做交叉核对，100 条均一致。第二个会员注册时间节点未作为项目发布时间。
7. 阅读公开需求，撰写简短中文摘要并分类；以正文、标题或平台地区提示判断地区要求，未把雇主所在国家当成承接者限制。
8. 筛掉 12 条不适合展示的记录，保存字段事实、访问日志、筛选决定和本地页面。

`₹` 明确记为 INR；只有 `$` 符号的记录保留符号，币种代码记为空，不擅自补为 USD。列表与详情的币种不同也保留两份原值；不进行汇率换算。地域未说明不等于确认全球可接。正文另有预算口径、附件或私下规格时，在详情中明确提示。

## 页面与验证

支持中英文/ID/技能搜索、9 类开发类型筛选、时间范围、地区要求、固定价/时薪、原币种、平台状态、时间排序、分页、原帖链接以及 JSON 快照下载。

已经在 Chrome 实际验证：近 30 天筛选得到 5 条，地区限制 6 条，地区加嵌入式组合筛选 1 条，冻结状态 1 条，INR 49 条；ID 搜索、中文搜索、零结果、分页、重置、详情联动和 12 条排除记录均正常。修正了筛选/重置后详情可能保留到当前页外的选择问题。原帖按钮的 href 与数据逐条一致；验证期间未再次点击来源链接增加请求。

JS 语法检查通过；当前桌面页面无横向溢出，无浏览器错误日志。未建立生产级自动测试或改动生产采集模块。数据完整性检查覆盖唯一 ID/URL、预算、中文摘要、地区标签和发布时间一致性。

## 结论与限制

**这个来源可以支撑本地页面实验；这次 programming 关键词样本的新鲜度偏低。** 88 条里只有 5 条在近 30 天发布，列表仍展示已授予和多年以前的记录。这个结果不能外推为全站的编程项目总量或每日新增量。

建议先在页面用“近 30 天”看 5 条，检查自己的技术栈和地区是否匹配；若继续做来源质量验证，优先研究更精准、更新的公开分类，而不是仅增加旧记录数量。

这是选定样本的静态快照，未核实雇主真实性，也未联系雇主确认可接单状态。没有官方接口接入；不表示平台批量使用授权、稳定采集或对外发布许可已得到确认。参考研究：`../platform-feasibility/freelance-platform-validation.md`。

## 文件

- `index.html`、`style.css`、`prototype.css`、`app.js`：本地原型。
- `data.js`、`truelancer-snapshot.json`：同一份 88 条展示数据、12 条排除记录与报告。
- `source-facts.json`：100 条详情的原始字段及有限原文片段，不保存整页或完整正文。
- `access-log.json`：111 次顶层页面读取记录。
- `listing-decisions.json`：列表卡片的筛选/未访问状态。
- `build_snapshot.py`：本地转换与中文摘要注释，**没有网络功能**；运行可重建 JSON 和 data.js。
- `validation.json`、`ui-verification.json`：数据与浏览器验证记录。
- `preview.png`：实际页面截图。

原型将保存在独立的 `prototype/truelancer-programming-snapshot` 本地分支，主分支代码不变；分支提交记录同时保存本次问题与结论。未向远端推送。
