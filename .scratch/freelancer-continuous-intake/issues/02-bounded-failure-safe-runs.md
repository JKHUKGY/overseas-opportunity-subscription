**What to build:** 项目运营者能够分辨成功零条、部分完成和真实失败；来源超时、限流、鉴权失败或响应异常时，已经保存的候选仍然可用，采集不会无限访问或用空结果覆盖旧数据。

**Blocked by:** 01 — 手动采集并持久保存候选。

**Status:** ready-for-agent

Execution: complete

- [x] 完整运行中所有搜索和后续详情请求共用总请求次数、每次超时及全轮耗时限制；限制无效时拒绝执行。页数、条数或预算达到上限时明确标记截断／部分完成。
- [x] 401、403 停止本轮后续来源请求；429 停止或推迟后续请求并给出最早可继续时间，优先使用来源等待信息，否则采用有界退避；不得立即无限重试。
- [x] 网络错误、5xx、整体非法响应和单条无效记录有可辨别的报告；单条无效可隔离，不抹掉同轮已成功结果。
- [x] 成功空列表、部分查询失败和全轮失败分别报告，已有候选、首次发现时间及有效持久状态均不被空结果覆盖。
- [x] 中断后再次执行允许重新读取来源，但不重复保存候选或破坏此前成功进度；尚未完成的运行能够被识别。
- [x] 报告提供成功、部分完成、失败或跳过结果、失败类别、实际范围、请求数及下一次允许执行时间，供后续调度直接使用；不泄露令牌、来源正文或敏感响应内容。
- [x] 从完整运行入口验证有效零条、部分查询失败、非法响应、单条坏数据、超时、401／403、带或不带等待信息的 429，以及达到请求／时间上限后的持久结果和报告。
- [x] 将可控时间推进后的再次执行纳入测试，验证退避未到期时不访问来源，到期后能够恢复；不以真实等待代替自动化验收。
