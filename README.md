# PROTOTYPE — 绘画机会采集实验

双击 `prototype.html` 即可查看。不需要启动服务器，不需要安装依赖。

问题：能否读取少量真实绘画买方项目，提取时间、预算、状态，再正确处理重复与结束记录？

## 实测结果 · 2026-09-22

- Freelancer：illustration、portrait 各查一页，最多五条，共十个不同 ID。curl 标准 HTTPS 请求返回 HTTP 200、API success，本次无令牌。又用脚本重跑相同三次请求成功；这不能外推为匿名访问一直有效或可大规模运行。
- 逐条阅读后：四条绘画候选、五条非绘画、一条综合设计待人工判断。四条绘画候选的原始发布时间均在采样前72小时内。样本不是每日总量，也不是随机抽样。
- ID 40725682 详情重读成功，原始时间、预算与状态可见。未读到已结束的真实项目，不声称验证了平台所有状态变迁。
- Upwork：内置浏览器不可用；Safari 补测到真人验证页，未读到列表，未调用API。
- VGen：公开买方入口仍未找到；没有机会样本。
- Safari 实际打开HTML并验证模拟需求入库、存档写入失败时保留详情、成功存档后再遇同网址排除。

## 重跑真实读取

从项目根目录执行：

```bash
python3 temp/prototype-opportunity-lab/probe.py
```

依赖 Python 3 和 curl。本次使用公开只读请求；可选令牌只从 `FLN_OAUTH_TOKEN` 环境变量读取，不写进页面或命令行参数。每次最多两次搜索和一次详情查询，不循环、不投标、不发邮件。401/403/429 不自动重试。

输出覆盖本目录 `snapshot.json` 和 `prototype.html`，刷新页面即可查看。只保存必要项目字段，不保存需求方账户资料。新项目或正文变化项目标为待整理，不复用失效摘要；中文总结是本次助手阅读后生成的标注，脚本并未接入持续运行的 AI 服务。

## 页面边界

真实快照与模拟状态独立。模拟操作仅在内存中执行，可导出独立结束记录 JSON；未实现长期存档数据库、定时调度或邮件发送。人民币汇率需要手填，未伪装为实时汇率；区间按下限筛选是实验规则，不是已确认的产品决定。

本目录为独立的本地 Git 原型仓库，分支 `prototype/drawing-intake`，不修改项目根目录的版本控制结构。保留原型作为实验依据，勿作生产系统使用。
